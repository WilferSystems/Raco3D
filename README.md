# Raco 3D

Sitio web estático de Raco 3D.

## Publicación

La página principal es `index.html`. Los estilos, configuración de Tailwind y recursos locales están en `css/`, `js/` y `assets/`. El sitio utiliza Tailwind CSS y Google Fonts desde sus CDN; la página puede publicarse directamente en Vercel sin proceso de compilación.

## Contacto

El formulario de cotización abre el cliente de correo con un mensaje dirigido a `contacto@raco3d.com`.
